- **压缩因子**：|dg*/dA2 * A2/g*| = |156.5 * 0.002/5.3| ~ 0.059
- **物理含义**：不动点 g* 作为 RG 流的"吸引子"，具有内在的误差缓冲能力。beta 函数在不动点附近的斜率 beta'(g*) ~ 0.95 决定了这一缓冲强度。
